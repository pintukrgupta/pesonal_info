# Personal Info — Portfolio Website

A **responsive personal portfolio / personal information website** built using **HTML**, **CSS**, **Bootstrap**, and basic **JavaScript**.  
This project is intended to showcase personal details, skills, and basic profile information in a clean and simple layout.

---

## 📌 Project Overview

This repository contains the source code for a static personal website that can be used as:
- A personal profile page
- A beginner portfolio website
- A simple resume-style web presence

The site is lightweight, easy to customize, and works well across devices.

---

## ✨ Features

- ✅ Responsive design using Bootstrap  
- ✅ Clean and minimal UI  
- ✅ Easy to edit and customize  
- ✅ Organized project structure  
- ✅ Suitable for GitHub Pages hosting
